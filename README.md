# Machine Learning Assignment 2 — M.Tech AIML

## a. Problem statement
Build and compare five supervised classification algorithms on one public classification dataset, evaluate them using six metrics, and provide a Streamlit interface that evaluates uploaded test data using saved models.

## b. Dataset description
**Dataset:** Wisconsin Diagnostic Breast Cancer (WDBC) dataset, available from the UCI Machine Learning Repository and distributed through `sklearn.datasets.load_breast_cancer`.

- Instances: 569
- Input features: 30 numeric features
- Target: `target` (0 = malignant, 1 = benign)
- Problem type: Binary classification
- Split: 80% training and 20% testing, stratified, `random_state=42`
- The full dataset is included as `dataset_full.csv`; `train_data.csv` and `test_data.csv` are also provided.

## c. GitHub Repository Link
https://github.com/2026aj05106-neha/MTech-AIML-ML-Assignment-2

## d. Models used and evaluation

The five models are Logistic Regression, Decision Tree, K-Nearest Neighbors, Gaussian Naive Bayes, and Support Vector Machine. StandardScaler is used within pipelines for Logistic Regression, KNN, and SVM. The decision tree and Gaussian Naive Bayes are trained without feature scaling.

### Evaluation metrics
| ML Model Name | Accuracy | AUC | Precision | Recall | F1 | MCC |
|---|---:|---:|---:|---:|---:|---:|
| Logistic Regression | 0.9825 | 0.9954 | 0.9861 | 0.9861 | 0.9861 | 0.9623 |
| Decision Tree | 0.9211 | 0.9163 | 0.9565 | 0.9167 | 0.9362 | 0.8341 |
| KNN | 0.9561 | 0.9788 | 0.9589 | 0.9722 | 0.9655 | 0.9054 |
| Naive Bayes | 0.9386 | 0.9878 | 0.9452 | 0.9583 | 0.9517 | 0.8676 |
| Support Vector Machine | 0.9825 | 0.9950 | 0.9861 | 0.9861 | 0.9861 | 0.9623 |

### Observations on model performance

| Model | Observation about performance |
|---|---|
| Logistic Regression | Joint-highest Accuracy (0.9825), Precision (0.9861), Recall (0.9861), F1 (0.9861) and MCC (0.9623); highest AUC (0.9954). |
| Decision Tree | Lowest Accuracy (0.9211), AUC (0.9163), F1 (0.9362) and MCC (0.8341) among the five models, although Precision remains 0.9565. |
| KNN | Second-highest F1 (0.9655); strong Recall (0.9722) and AUC (0.9788). |
| Naive Bayes | AUC is relatively high (0.9878), but Accuracy (0.9386), F1 (0.9517) and MCC (0.8676) are lower than KNN, Logistic Regression and SVM. |
| Support Vector Machine | Ties Logistic Regression on Accuracy, Precision, Recall, F1 and MCC; AUC (0.9950) is marginally below Logistic Regression. |

**Overall winner:** Logistic Regression. Logistic Regression and SVM are tied on Accuracy, Precision, Recall, F1 and MCC; Logistic Regression has a slightly higher AUC (0.9954 versus 0.9950), so it is selected as the tie-break winner. The winner is specific to this dataset and the stated train/test split.

## Streamlit application
The application supports:
1. Uploading a test CSV file.
2. Selecting one of the five saved classifiers.
3. Displaying Accuracy, AUC, Precision, Recall, F1 and MCC.
4. Displaying a confusion matrix and classification report.
5. Downloading a CSV containing predictions.

The application loads saved model files and does not retrain on uploaded test data.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

Upload `test_data.csv` in the app. The CSV must include all 30 feature columns and the `target` column. `target_name` is optional and is ignored during prediction.

## Deployment on Streamlit Community Cloud
